# ドラサポ — 物流ドライバー採用・管理アプリ（HTMLモック）

貨物運送会社向けの、ドライバー採用〜稼働〜車両管理を一元化するアプリの **HTMLモック** です。
DB接続は不要。全画面がリンクで繋がっており、ブラウザだけで一通りの操作が動きます
（データは `localStorage` に保存され、画面をまたいで保持されます）。

## 使い方

`index.html` をブラウザで開くだけです（サーバー不要）。

```
open index.html        # macOS
# または index.html をダブルクリック
```

データを初期状態に戻したい場合は、ブラウザのコンソールで `DB.reset()` を実行してリロードしてください。

## 画面一覧

| 画面 | ファイル | 内容 |
|------|----------|------|
| ダッシュボード | `index.html` | 採用パイプライン・架電状況・本日の予定・稼働/車両サマリー |
| 候補者一覧 | `candidates.html` | 媒体/会社/経験で絞り込み・候補者追加 |
| 候補者詳細 | `candidate-detail.html` | 架電ログ・面接調整・面接結果・契約→ドライバー登録 |
| CSVインポート | `import.html` | 求人アカウント単位でCSVを一括取込（媒体はアカウントに自動連動・サンプルデータで試せます） |
| 架電管理 | `calls.html` | 1〜3回目の架電をステータス色分けで管理 |
| 面接管理 | `interviews.html` | 面接予定/実施結果（来社・リモート） |
| ドライバー管理 | `drivers.html` | 契約→納車→研修→稼働の進捗管理 |
| ドライバー詳細 | `driver-detail.html` | 各ステータス更新・車両割当・解除申請（2ヶ月ルール自動計算） |
| 車両管理 | `vehicles.html` | リース・乗車者・返却/修理ステータス |
| 車両詳細 | `vehicle-detail.html` | 返却→修理→完了のログ・費用管理 |
| 商談ログ | `negotiations.html` | 荷主・会社ごとの商談履歴（いつ・誰と・何を） |
| 荷主・会社 | `companies.html` | 荷主＞会社（求人アカウント）の階層管理 |
| スケジュール | `schedule.html` | 面接/架電/納車/研修/商談のカレンダー（Googleカレンダー連携イメージ） |

## 動く主なフロー（モック）

- **CSVインポート**：`import.html` で取込先の**求人アカウントを1つ選択** →「サンプルCSVを読み込む」→ プレビュー → 登録 → 候補者一覧に反映（そのアカウントで絞り込み可能）
- **採用フロー**：候補者詳細で 架電記録 → 面接設定（カレンダー登録）→ 面接結果 → 契約 → ドライバーへ自動登録
- **稼働フロー**：ドライバー詳細で 納車済 → 研修 → 稼働開始、車両割当、解除申請（終了日を自動計算）
- **車両フロー**：車両詳細で 返却 → 修理入庫（費用登録）→ 修理完了 → 空き車両へ

## 用語

- **荷主**：佐川急便・ヤマト運輸・Amazon など元請け
- **会社**：荷主の下請け（自社が仕事をもらう単位／求人アカウント）
- **ドライバー**：会社に紐づく業務委託ドライバー

## 構成

```
index.html ほか各画面HTML
assets/css/style.css   … 共通デザイン
assets/js/data.js      … モックデータ（localStorage）
assets/js/app.js       … 共通レイアウト・UIロジック
```

> これは提案用のUIモックです。実データ連携・認証・権限管理などは含みません。
